# Criação da página /chatbot

Criar a página /chatbot usando Angular Material como biblioteca oficial de componentes e mantendo o design do projeto.

Objetivo: Criar tela para o usuário experimentar o funcionamento do sistema em RAG. 
A tela deve funcionar como um chat real de conversas entre o usuário e o sistema.

Comportamento esperado:
- Cliente abre a tela e manda sua mensagem
- Aplicação frontend manda a mensagem do cliente para o sistema backend processar
- Aplicação frontend recebe o retorno de processamento do backend, trata essa resposta e enviar de volta para o usuário

## Fora do escopo: 
- modo escuro
- histórico (tudo é perdido se o usuário atualizar a tela)
